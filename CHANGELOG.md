# Changelog

## 0.1.0

Initial public release of Coati, an enterprise model gateway.

- OpenAI Chat Completions, OpenAI Responses and Anthropic Messages interfaces.
- Model routing, credential pools, quotas, personal channels and usage records.
- Self-hosted administration console with users, roles and access tokens.
- Docker deployment and Apache-2.0 licensing.

Client applications, CLI tools, agent plugins and runtime installers are excluded.
