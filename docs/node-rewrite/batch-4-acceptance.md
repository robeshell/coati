# 第四批：最近绑定轮转修正

日期：2026-09-26。仅完成 S06 的最近绑定排序部分，不代表 S06 或整体调度等价。

## 实现

- `gw_session_bindings` 增加唯一递增 id、updated_at；新建记录和半 TTL 续期记录更新时间。
- 最近绑定按 updated_at/id 倒序，不再按 expires_at/scope 排序，避免不同 TTL 改变轮转。
- 服务传入本轮候选账号；绑定数量、最近绑定和活动租约仅统计候选范围。未传候选列表的仓库调用保持原范围，空列表为空。
- 旧绑定保留，updated_at 初始化为迁移时间。不能还原迁移前真实的先后顺序；新增或续期后开始准确记录。
