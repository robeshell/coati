## 修复

1. 独立搜索和服务端工具子请求不再使用写死的125秒预留期限，沿用普通模型请求的reservationTtlSeconds配置（默认3600秒，环境配置最少300秒）。Python的搜索/抓取使用统一reserve_quota期限；网络执行期限仍单独控制，已有预留不追溯修改。
2. Tavily提取及原生模型抓取委托共用UTF-8截断：显式max_content_tokens采用保守字节上限，不拆中文/emoji；保留既有truncated=true，默认12000字符上限保留。此前原生回退按JS字符slice，可能超出字节预算并切断代理对。
3. 原生能力观察按web-search/web-fetch分别保存。账号不支持搜索不代表不支持抓取。多工具请求要求声明的能力均已确认；上游明确指出某工具不支持时，只失效该工具，普通待执行调用也只影响对应工具。连接配置变动仍使旧观察失效。
