## 本次修复

- **C01 缓存验证**：不再要求先创建 PAT。默认使用登录用户内部身份，仍走用户额度、RPM、并发和正常账本。每用户一个不可用于 Bearer 登录的 internal-cache 记录，列表、轮换、撤销及 PAT 历史入口排除它；GET 模型目录不创建身份。也可显式选择本人有效 PAT 验证令牌策略。浏览器已看到当前用户默认项、模型列表和表单，未提交收费任务。
- **P03 扩展字段**：将 18 个广义 TODO 换成九协议组合 × JSON/SSE 的具体 wire 检查。默认 python 策略接受并按转换器降级，strict 对跨协议未知请求先拒绝，对未知响应块/事件终止转换；同协议保留。检查私有标记不泄漏、无遗留 reserved/租约。这里只关闭当前声明契约的验收义务，不承诺任意未来供应商字段。
- **P04 Responses**：源码确认 Python provider adapter 总是设置 store:false。因此默认策略接受 store:true 并强制关闭存储，strict 仍拒绝。非空 previous_response_id 拒绝；后续补齐 background/conversation 默认原生透传，strict 可选拒绝。限定转发策略与 Python 一致，不实现网关状态存储。
- **T03/T04 Messages 工具**：流式客户端请求先完成内部非流式模型/工具循环，再发出最终 SSE。修复原生上游返回普通搜索 tool_use 时直接把未执行工具流返给客户端的问题。历史搜索/抓取块在本轮没有工具声明时也会归一化，解码 coati1 正文，兼容 Python 带 padding 的 URL-safe Base64；不会重新搜索历史来源。
- **C02 探测静默期**：后台候选与抢占同时检查 last_checked_at 和 last_probe_at，最近已检测的账号不会立即被后台重复探测；单次人工检查仍可立即执行。独立 worker 默认显式启动的部署差异保留。
- **A05 角色迁移**：新增独立设备确认动作、模型服务测试权限和个人用量权限组。旧 agent_device_confirm/action、agent_llm_keys_test、agent_my_usage 分别映射；不会把设备确认角色变成 PAT 创建角色。0039/0040 为已存在 Node 编辑/创建角色保留此前拥有的对应确认/探测能力，后续可独立配置。
- **RBAC 种子**：增量同步按实际父菜单 ID 关联子菜单，而不是假设历史数据库 ID 等于种子推荐 ID。保持现有 ID 和角色引用，空库迁移不预插入菜单，仍允许旧库归档导入。
