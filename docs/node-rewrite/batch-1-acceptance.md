## 修正

- **Q03 过期预留不充当实际消耗。** Python 只将时效内 reserved 计入额度；Node 原先将过期预留转换为 interrupted 并按整个预留量计费。现在回收仍标记 interrupted，但输入/输出计数为0，usage_source=unknown，原 reserved_tokens 保留供追查。统一的日额度、令牌用量、总览和分析聚合排除 interrupted。0是存储占位，不代表供应商实际消耗为0。旧 interrupted 原始计数不重写，但同样不再计入网关额度。实际供应商账单需另行核对。
- **A02 新建令牌默认值。** native API和新建表单统一为不过期、独立日额度/RPM/并发默认0；0表示不额外限制，仍受用户及上游账号限制。支持显式1–3650天或null不过期，表单0转null。已有令牌不变，上游账号并发默认值仍为10，设备流程另行验收。
- **S09 最终状态码。** 实际HTTP错误耗尽重试后保留上游状态；硬账号错误只提取已脱敏message，不透出完整账号错误包。连接失败/协议失败仍按自身类别处理，已开始输出的SSE不会改写HTTP200。现有重试和冷却规则未改变。
