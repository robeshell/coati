# Coati icon

The project icon depicts a coati. It was generated with the built-in OpenAI image generation tool, then resized with macOS `sips`, preserving transparency.

- Main icon: `portal/frontend/public/logo.png` (512 × 512)
- Browser icon: `portal/frontend/public/favicon.png` (64 × 64)

## Generation prompt

```text
Use case: logo-brand. Generate ONE final production-ready square project icon for Coati, an enterprise model gateway named after the coati animal (长鼻浣熊). A distinctive coati head in clean bold flat vector-like illustration: recognizable elongated narrow snout pointing slightly to the right, small rounded ears, warm cream muzzle and eye markings, dark charcoal nose and eyes. Friendly, alert, intelligent, professional rather than childish. Compact strong silhouette with very few large shapes, readable at 24px. Center the head large occupying about 85% of the canvas. Restrained warm chestnut and cream animal colors with a deep teal accent consistent with the existing product. Genuine transparent background outside the animal, no surrounding badge, no text, no letters, no C monogram, no terminal symbols, no watermarks, no gradients, no shadow, no fur texture. The result should be a single isolated animal logo, not a sheet or a mockup. Save the output as a PNG image.
```
