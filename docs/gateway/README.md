- [配置](configuration.md)：环境变量、凭证和限额。
- [运维](operations.md)：安装、健康检查、备份和版本升级。
- [测试](testing.md)：验证命令及环境隔离。

管理模块与公共组件开发规范见 [框架架构](../architecture.md) 和 [前端设计系统](../frontend-design-system.md)。
